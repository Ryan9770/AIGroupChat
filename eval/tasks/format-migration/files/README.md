# record-store

레코드를 JSON 문자열로 직렬화·역직렬화한다.

## 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `name` | string | 필수. 비어 있으면 안 된다. |
| `tags` | string[] | 선택. 없으면 `[]`. |

## 포맷 버전

직렬화 결과에는 `v` 필드가 들어간다. 현재 버전은 `1`이다.

`fixtures/legacy.json`은 이전 릴리스가 **실제로 디스크에 저장한** 레코드 샘플이다.
고객 설치본에는 이 형식의 데이터가 아직 남아 있다.
