# 이끼섬의 친구들 · Moss & Monsters v3

농장에서 탐험을 준비하고, 던전 자원으로 생활과 탐험 능력을 키우는 싱글플레이 픽셀 게임 프로토타입입니다. 집·농장·던전이 별도 장면이며, 작물과 하루 기력을 어디에 사용할지 선택합니다.

## 실행

이 폴더에서 `node serve.mjs`를 실행한 뒤 [게임 열기](http://127.0.0.1:4179/)로 접속합니다. 이미 실행 중이면 열린 게임을 새로고침하세요. 외부 에셋이나 패키지 설치, 빌드는 필요 없습니다.

저장은 브라우저와 주소별로 구분됩니다. **v3는 새 게임으로 시작하며 기존 v2 저장은 보존합니다.** 이전 버전 파일은 `archive/v2`에 있습니다.

## 조작과 공간

- WASD / 방향키: 이동. 지도 클릭: 해당 위치로 이동하거나 대상과 상호작용.
- E: 가까운 대상과 상호작용. J / Space: 던전 공격. 공격키를 누르고 있어도 됩니다.
- 오른쪽 작업 버튼: 해당 시설로 걸어가 작업합니다. 이동키로 자동 이동을 취소합니다.
- 위쪽 생활·씨앗·친구·탐험 버튼: 오른쪽의 해당 도구로 이동합니다.

| 공간 | 하는 일 |
|---|---|
| 집 | 아래쪽 문으로 농장에 나가기, 침대에서 잠들기, 비상 씨앗 받기 |
| 농장과 이끼섬 | 농사, 채집, 조리, 판매, 시설 개선, 친구 수집, 연구 |
| 던전 | 적의 공격 예고를 피하며 전투, 전리품 수집, 다음 층 또는 귀환 선택 |

집으로 돌아가기 버튼은 농장에서는 집 문까지 이동합니다. 던전에서는 먼저 전리품을 보관하고 귀가합니다. 수면은 집 내부 침대에서 가능합니다.

## 첫 탐험

1. 집 아래쪽 문을 클릭해 농장으로 나갑니다.
2. 익은 당근 두 칸을 수확합니다. 기본 수확량은 칸당 2개입니다.
3. 화덕에서 당근 2개로 도시락 하나를 만듭니다. 남은 당근과 씨앗은 다음 날을 위해 나눠 씁니다.
4. 탐험 카드의 출발 버튼이나 농장 북동쪽 동굴을 이용합니다.
5. J / Space로 적을 공격합니다. 붉은 공격 예고 범위를 벗어나 피해를 피합니다.
6. 적을 모두 정리한 뒤 광석과 유물 기록을 챙겨 귀환합니다.
7. 광석 4, 목재 3, 12G로 연구하면 공격력이 오르고 2층이 열립니다.

이동·귀환·수면에는 기력을 쓰지 않습니다. 기력이 부족하면 귀환해 수프를 먹거나 집에서 잠듭니다.

## 제한된 자원과 작물 사용처

시작 자원은 당근 씨앗 8개와 익은 당근 두 칸입니다. 심을 때 씨앗 1개와 기력 2를 씁니다. 작물은 실시간으로 자라지 않으며 집에서 잠든 뒤 아침에 익습니다.

| 행동 | 비용 / 결과 |
|---|---|
| 당근 파종 | 씨앗 1 + 기력 2 |
| 수확 | 기력 1. 당근 기본 2개, 농장 슬라임·두더지 각각 +1 |
| 야외 채집 | 기력 2. 허브·목재 노드는 하루 한 번 |
| 수프 조리 | 당근 2 + 허브 1 + 기력 1 → 수프 1 |
| 수프 식사 | 체력 +30, 기력 +6. 하루 최대 두 끼, 모두 가득하면 소비하지 않음 |
| 도시락 제작 | 당근 2 + 기력 1 → 도시락 1. 탐험 입장 한 번에 하나 소비 |
| 씨앗 받기 | 당근 1 + 기력 1 → 당근 씨앗 2 |
| 동료 훈련 | 당근 2 + 기력 1. 하루 한 번, 유대 최대 3 |
| 당근 판매 | 당근 1 → 2G |
| 수프 납품 | 수프 1 → 12G, 하루 두 번. 부엌 개선 후 18G |

판매 대금은 즉시 받습니다. 수면은 체력·기력 회복, 식사 횟수 초기화, 작물 성장, 채집과 납품 의뢰 갱신을 담당합니다. 초기 최대 기력은 40이며 연구 2단계부터 50입니다. 시계가 22시에 도달해도 강제로 잠들지 않습니다.

당근·당근 씨앗·심어진 당근이 모두 없으면 집의 비상 꾸러미에서 하루 한 번 당근 씨앗 2개를 받습니다. 꽃은 나방과 등불을 밝힐 때 씨앗 2개를 얻고, 수확 때 씨앗 1개가 돌아옵니다. 꽃 한 칸은 꽃 1개를 생산하며, 나방을 농장에 두고 잠들어야 자랍니다.

## 친구와 시설

친구에게 당근을 선물해 수집합니다. 슬라임 1개, 두더지 2개, 나방 3개가 필요합니다. 한 친구는 농장 또는 동행 중 하나를 맡고, 동행은 한 마리까지입니다.

| 친구 | 농장 효과 | 동행 효과 |
|---|---|---|
| 물방울 슬라임 | 당근 수확 +1 | 개울 길 개방 |
| 뿌리 두더지 | 당근 수확 +1 | 바위 지름길 개방, 목재 채집 +1 |
| 불씨 나방 | 달빛꽃 재배 | 숲 등불 개방, 허브 채집 +1 |

훈련 유대는 동행 중 단계당 공격력 +2를 더합니다. 역할은 던전 밖에서 바꿉니다. 밭 확장은 24G + 목재 3으로 8칸에서 12칸으로, 부엌 수리는 30G + 목재 4로 수프 납품가를 올립니다. 친구 셋과 꽃 1개로 고목을 복구할 수 있으며, 시설과 고목 복구 뒤에도 던전 연구 목표가 남습니다.

## 던전과 계속되는 목표

던전은 고정된 3개 층입니다. 각 층의 적을 모두 처치하면 전리품과 기록을 수집하고 다음 층으로 내려갈 수 있습니다. 개방된 층은 출발 전에 선택할 수 있고, 한 탐험 안에서 층을 내려갈 때는 도시락을 추가로 쓰지 않습니다.

기본 공격력은 12, 공격 한 번에 기력 1을 씁니다. 붉은 예고 후 적의 공격이 발생합니다. 체력이 0이 되면 집으로 돌아오며 체력 35, 기력 0이 됩니다. 이번 탐험에서 아직 보관하지 않은 자원과 기록만 잃습니다. 이전 자원·동전·친구·시설은 유지됩니다.

| 연구 | 비용 | 보상 |
|---|---|---|
| 1단계 | 광석 4 + 목재 3 + 12G | 공격력 +4, 2층 출발 |
| 2단계 | 유물 2 + 달빛꽃 1 + 20G | 최대 기력 50, 3층 출발 |
| 3단계 | 결정 3 + 당근 4 + 30G | 탐사 등대 복구, 탐사 의뢰 개방 |

귀환 시 층별 유물 도감과 클리어 횟수도 기록됩니다. 연구 완료 후에는 광석 3 → 12G·당근 씨앗 2, 유물 1 → 18G·허브 2, 결정 1 → 24G·꽃 씨앗 1 의뢰가 순환합니다. 이번 프로토타입의 반복 목표이며 던전이 무한 생성되는 것은 아닙니다.

## 저장과 재접속

브라우저 localStorage의 `moss-and-monsters:v3`에 자동 저장합니다. `moss-and-monsters:v2`는 변경하지 않습니다. 저장은 주요 행동, 주기적 자동 저장, 탭 종료 시 시도하며 실패하면 화면에 안내합니다.

**던전 중 재접속하면 집에서 시작하며 미보관 전리품은 사라집니다.** 저장 버튼을 눌러도 이번 탐험의 전리품을 보관하는 것은 아닙니다. 닫기 전에 귀환하세요. 이미 소비한 도시락은 환불되지 않습니다. 이 규칙은 탐험 카드와 저장 상태에도 표시합니다.

손상된 저장은 새 게임으로 시작할 수 있도록 처리합니다. 처음부터 버튼은 확인 후 v3 저장만 초기화합니다.

## 검증과 범위

실행 검증은 `node qa-v3.cjs`, 화면 검증은 `node qa-visual-v3.cjs`입니다. 이 검증 스크립트는 현재 개발 환경의 Playwright·Chromium 경로를 사용합니다. 다른 환경에서는 해당 경로 설정이 필요합니다. 최신 결과와 제한은 [QA.md](QA.md)를 확인하세요.

[방향 문서](DIRECTION_V3.md)에 여섯 가지 피드백과 설계 대응을 정리했습니다. 상용판 엔진·Steam 패키징·가격과 플레이 분량은 아직 확정하지 않았습니다. 작은 고정 던전과 제한된 생산으로 핵심 선택을 검증하는 단계입니다.
