# 이끼섬의 친구들 · Moss & Monsters v2

농사·채집·요리·납품으로 생활비를 벌고, 몬스터 친구와 함께 농장과 부엌을 되살리는 싱글플레이 생활 게임 프로토타입입니다. 전투, 작물 고사, 강제 취침은 없습니다.

## 실행

이 폴더에서 `node serve.mjs`를 실행한 뒤 `http://127.0.0.1:4179`를 엽니다. 또는 `python -m http.server 8000`을 사용할 수 있습니다. 설치·빌드·외부 에셋 다운로드는 필요 없습니다.

`index.html`을 직접 열어 플레이하는 것도 가능하지만, 브라우저에 따라 로컬 파일의 저장 기능이 제한되므로 서버 실행을 권장합니다. 저장은 브라우저와 주소별로 구분됩니다. 서버 주소나 포트를 바꾸면 별도 저장으로 취급됩니다.

## 조작

- WASD / 방향키: 이동
- E / 스페이스: 가까운 밭, 친구, 채집물, 작업장과 상호작용
- 지도 클릭: 자동 이동. 상호작용 가능한 타일을 클릭하면 도착 후 작업
- 오른쪽 생활과 작업 버튼: 실제 작업장까지 걸어가서 요리·납품·시설 개선·취침 진행. 이동키로 자동 이동을 취소할 수 있습니다.
- 씨앗 버튼: 빈 밭에 심을 작물 선택. 씨앗은 무제한
- 친구의 농장 / 동행 버튼: 역할 변경. 동행은 1마리이며 이전 동행은 농장으로 돌아갑니다.
- 지금 저장: 수동 저장. 소리 버튼: 짧은 효과음 켜기/끄기
- 처음부터: 확인 후 이 게임의 저장만 삭제하고 초기화

## 하루의 생활

아침 08:00에 시작합니다. 실제 1초에 게임 시간 2분이 흐르며 22:00에서 시계가 멈춥니다. 밤에도 계속 일할 수 있고, 쓰러지거나 손해를 보지 않습니다. 실제 날짜는 오두막에서 잠든 뒤에만 증가합니다.

1. 처음 익어 있는 당근을 수확하고 빈 밭에 씨앗을 심습니다.
2. 섬의 허브와 쓰러진 가지를 클릭해 허브·목재를 채집합니다. 각 지점은 하루에 한 번 채집할 수 있습니다.
3. 야외 화덕에서 **당근 2개 + 허브 1개 → 수프 1개**를 만듭니다.
4. 토리의 납품대에 **수프 1개 → 12G**로 납품합니다. 수프 의뢰는 하루 2건입니다. 당근은 개당 2G에 제한 없이 팔 수 있습니다.
5. 동전과 목재로 시설을 고칩니다. 돈이 부족하면 다시 농사와 납품을 하고, 채집물과 의뢰가 소진되면 오두막에서 하루를 마무리합니다.

하루 마무리 화면에서 수확·채집·요리·의뢰 수, 수입, 시설 지출, 남은 동전을 확인할 수 있습니다. ‘아직 할 일이 있어요’로 같은 날을 이어갈 수 있습니다. ‘다음 날 아침으로’를 누르면 새 의뢰와 채집물이 돌아오고, 자랄 수 있는 작물은 모두 익습니다. 나방이 농장에 없으면 달빛꽃은 밤에도 성장이 멈춥니다. 자는 데 최소 활동량이나 시간 조건은 없습니다.

## 농장과 부엌 개선

| 개선 | 비용 | 실제 효과 |
|---|---|---|
| 밭 4칸 확장 | 24G + 목재 3 | 8칸에서 12칸으로 증가. 밭 가운데 새 4칸에 작물을 심을 수 있음 |
| 부엌 지붕 수리 | 30G + 목재 4 | 화덕 위에 지붕이 생기고, 이후 수프 의뢰 보상이 18G로 증가 |

두 개선은 원하는 순서로 구매할 수 있습니다. 지붕 수리로 이미 끝낸 의뢰가 초기화되지는 않습니다.

## 몬스터 친구와 탐험

| 친구 | 선물 | 농장 역할 | 동행 역할 |
|---|---|---|---|
| 물방울 슬라임 | 당근 1개 | 작물 성장 속도 ×2 | 개울에 영구 징검다리 만들기 |
| 뿌리 두더지 | 당근 2개 | 한 번 수확할 때 작물 +1 | 바위 지름길 열기, 목재 채집 +1 |
| 불씨 나방 | 당근 3개 | 달빛꽃 재배 가능 | 숲 등불 밝히기, 허브 채집 +1 |

친구는 한 번에 한 역할만 맡습니다. 두더지와 동행하면 목재를 더 얻지만 농장 수확 보너스는 잠시 사라집니다. 나방과 동행하면 허브를 더 얻지만 달빛꽃 성장은 멈춥니다. 슬라임을 동행으로 데리고 다니면 농장 성장 보너스는 없어집니다. 열린 길은 역할을 바꾸어도 유지됩니다.

슬라임에게 선물한 뒤 동행으로 바꾸고 개울 표식 앞에서 E를 누릅니다. 개울 너머에서는 두더지와 나방 중 누구를 먼저 만날지 정할 수 있습니다. 북쪽 숲은 두더지로 바위를 깨고 지름길로 가거나, 맨 동쪽의 긴 오솔길로 돌아갈 수 있습니다. 나방과 동행해 숲의 등불을 밝히면 달빛꽃 씨앗을 얻습니다. 나방을 농장으로 보내고 달빛꽃을 길러 남쪽 고목에 전합니다.

**친구 3종 + 고목 복원 + 밭 확장 + 부엌 수리**를 달성하면 생활 터전 복원 화면이 나타납니다. 날짜 수에 따른 강제 대기 조건은 없습니다. 완료 후에도 계속 농사·채집·요리·납품·취침을 할 수 있습니다.

기본 성장 시간은 당근 12초, 달빛꽃 25초입니다. 수확 4회마다 농사 레벨이 올라 성장 속도에 5% 보너스가 붙으며 최대 보너스는 25%입니다.

## 저장과 복구

진행 상황은 작업 후, 2초마다, 탭을 떠날 때 이 브라우저의 `localStorage`에 자동 저장됩니다. ‘지금 저장’으로 수동 저장할 수도 있습니다. 새로고침 후 시작 화면에 저장된 날짜와 ‘이어서 하기’가 나타납니다. 자동 이동은 저장에서 제외되며, 재개 후 직접 다음 행동을 선택합니다. 게임을 닫은 동안 시간이나 작물 성장은 진행되지 않습니다.

저장 키는 `moss-and-monsters:v2`, 스키마 버전은 `2`입니다. 날짜·자원·밭·친구 역할·시설·채집 상태를 검증하고 지원하지 않거나 손상된 저장은 불러오지 않습니다. 저장 공간 부족이나 브라우저 차단이 발생하면 화면 하단과 알림으로 알려 주며, 현재 탭에서 플레이는 계속할 수 있습니다. 저장 실패 시 탭을 닫으면 진행이 사라질 수 있습니다. ‘처음부터’는 확인 후 이 게임 키만 삭제합니다. 다른 사이트나 게임의 저장을 지우지 않습니다.

## 구현과 검증

Vanilla HTML / CSS / JavaScript, 720×480 Canvas, 고정 60Hz 업데이트, 충돌 검사, 클릭 경로 탐색, title / playing / summary / won 상태로 구성했습니다. 모든 픽셀 요소는 코드로 직접 그렸습니다. 외부 이미지·폰트·라이브러리가 없습니다. Steam 배포용 빌드나 본편 분량은 포함하지 않습니다.

- `node --check game.js`: JavaScript 문법 검사
- `mossGame.getSnapshot()`: 브라우저 콘솔에서 현재 상태의 읽기 전용 사본을 확인하는 플레이테스트 도구
- `archive/v1`: 앞선 농사·몬스터 중심 프로토타입 보관본
- `QA.md`: 실제 입력 기반 검증 기록

스냅샷은 `day`, `dayTime`, `dayStats`, `coins`, `herbs`, `wood`, `soup`, `upgrades`, `nodes`, `completed`와 기존 이동·농사·탐험 상태를 포함합니다. 수입은 총수입, 지출은 시설 구매 비용으로 따로 기록하며 하루가 바뀌면 하루 기록만 초기화됩니다.
