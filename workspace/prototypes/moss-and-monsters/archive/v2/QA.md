# v2 생활형 프로토타입 플레이 테스트

2026-09-09 · **PLAYABLE** · Chromium 149 / Playwright

실제 키보드·마우스 입력으로 농사, 채집, 요리, 납품, 시설 확장, 고목 복원, 다음 날 생활까지 확인했다. 최종 실행에서 **29개 확인 항목 통과**, 브라우저 콘솔 및 JavaScript 오류 **0건**이었다. 게임 상태는 읽기만 했고, 자원·좌표·날짜·승리 상태를 직접 바꾸거나 시간을 가속하지 않았다.

| 확인 범위 | 실제 결과 |
|---|---|
| 기본 조작·농사 | 키보드 이동/E 수확, 클릭 이동·상호작용, 8칸 당근 재배·정상 시간 성장·수확 정상 |
| 몬스터 | 당근을 소비해 3종 영입. 동행 능력으로 다리·돌문·등불 해금, 해당 동행이 없으면 해금되지 않음 |
| 역할 효과 | 농장 두더지로 8칸에서 당근 16개 수확. 나방을 동행으로 바꾸면 달빛꽃 성장이 정지하고 농장 복귀 시 재개 |
| 채집 | 허브·목재는 각 장소에서 하루 1회. 같은 장소 재클릭은 추가 자원을 주지 않음. 나방 동행 허브 2개, 두더지 동행 목재 2개 확인 |
| 요리 | 당근 2개+허브 1개 → 수프 1개. 재료 부족 시 자원 보존 |
| 납품·판매 | 수프 의뢰 12G, 하루 2회 제한. 세 번째 의뢰는 수프·자원을 소비하지 않음. 제한을 채운 뒤에도 당근 1개를 2G에 판매 가능 |
| 밭 확장 | 24G+목재 3개를 소비해 8칸→12칸. 추가된 가운데 밭에 실제로 심고 수확 |
| 부엌 수리 | 30G+목재 4개 소비. 지붕이 화면에 생기고 의뢰 표시가 18G로 변경. 다음 날 실제 납품에서 18G 수령 |
| 최종 목표 | 세 친구·고목 복원·두 시설을 **1일 차 약 96초**에 달성. 임의의 날짜 조건 없이 완료되며 이후 계속 생활 가능 |
| 하루 마무리 | 수확·채집·요리·납품·수입·지출 요약 확인. 1일 차 실제 수입 54G/지출 54G. 마무리 취소 후 계속 가능 |
| 다음 날 | 수면으로 2일 차 진입, 의뢰 횟수 초기화, 덜 자란 작물 성숙, 채집 장소 재이용 및 동행 보너스 재적용 확인 |
| 저장·이어하기 | 저장 후 새로고침·이어하기로 자원, 두 시설, 날짜, 작물, 채집 상태, 몬스터, 완료 상태 보존 |
| 재시작 | 취소 시 생활 상태 보존. 확인 시 자원·시설·친구·날짜·진행과 저장 삭제. 다시 시작한 뒤 수확 가능 |
| 손상 저장 | 별도 브라우저 세션 3개에서 깨진 JSON, 음수 동전, 미지원 저장 버전을 주입한 뒤 새 게임으로 안전하게 시작 |
| 화면 | 1440×900 및 1024×768에서 가로 넘침 없음. 한국어와 밭 확장·부엌 지붕·고목 복원 표현 확인. 작은 화면의 사이드바는 별도로 스크롤 |

최종 전체 검증은 약 113초였다. 알려진 경로를 자동으로 입력한 기능 검증이며, 사람의 첫 플레이 시간이나 재미를 검증한 결과는 아니다. 외부 플레이어 평가는 아직 실시하지 않았다. 저장 오류 사례만 별도 세션에서 의도적으로 손상된 `localStorage`를 넣었으며, 정상 완주에는 상태 주입을 사용하지 않았다.

게임 버그로 확인된 blocker·major 항목은 없다. 최초 실행의 일일 수입 검증식은 수프 매출 24G만 가정했으나 원물 판매를 포함한 실제 총수입은 54G였으므로, 테스트를 실제 수입·지출과 비교하도록 수정하고 재실행했다.

## 재현과 증거

`serve.mjs` 서버를 실행한 상태에서 이 폴더에서 `node qa-v2.cjs`를 실행한다. 환경별로 `PLAYWRIGHT_MODULE`, `CHROME_PATH`, `GAME_URL`을 지정할 수 있다. 현재 환경에서는 번들 Playwright와 캐시 Chromium을 사용한다.
