# 이끼섬의 친구들 · Moss & Monsters

작물을 길러 몬스터와 친구가 되고, 친구를 농장과 탐험에 배치하며 새로운 길을 여는 작은 싱글플레이 프로토타입입니다. 전투, 시간 제한, 작물 고사, 유료 자원은 없습니다.

## 실행

`index.html`을 데스크톱 브라우저에서 열면 됩니다. 설치나 빌드, 인터넷 연결이 필요하지 않습니다. 필요하면 이 폴더에서 `node serve.mjs`를 실행하고 `http://127.0.0.1:4179`를 엽니다. 또는 `python -m http.server 8000`으로 실행할 수 있습니다.

## 조작

- WASD / 방향키: 이동
- E / 스페이스: 가까운 밭, 몬스터, 길목, 고목과 상호작용
- 지도 클릭: 해당 위치까지 자동 이동. 밭이나 몬스터를 클릭하면 가까이 이동한 뒤 상호작용
- 오른쪽 씨앗 버튼: 빈 밭에 심을 작물 선택
- 친구의 농장 / 동행 버튼: 역할 변경. 동행은 1마리이며, 이전 동행은 농장으로 돌아갑니다.
- 소리: 기본 꺼짐. 버튼으로 짧은 효과음 활성화
- 처음부터: 확인 후 초기화

## 완주 흐름

1. 밭의 익은 당근을 수확합니다. 빈 밭에 무료 씨앗을 심어 두면 다음 만남이 빨라집니다.
2. 북동쪽 슬라임에게 당근 1개를 선물합니다.
3. 슬라임을 동행으로 선택하고 개울 중앙 표식에서 E를 눌러 영구 징검다리를 만듭니다.
4. 동쪽 두더지에게 당근 2개를 선물합니다. 슬라임을 농장에 두면 성장이 2배 빨라집니다.
5. 두더지를 동행으로 선택하고 동쪽 섬 북쪽의 밝은 바위에서 E를 눌러 지름길을 엽니다. 이 단계는 선택 사항이며, 맨 동쪽의 긴 오솔길로도 숲에 갈 수 있어 두더지와 나방을 만나는 순서를 자유롭게 정할 수 있습니다.
6. 북쪽 숲의 나방에게 당근 3개를 선물합니다. 두더지를 농장에 두면 수확량이 1 증가합니다.
7. 나방과 동행하여 숲 오른쪽 등불을 밝히고 달빛꽃 씨앗을 얻습니다.
8. 나방을 농장에 보내고, 달빛꽃 씨앗을 선택하여 왼쪽 농장의 빈 밭에 심습니다. 나방이 동행 중이면 달빛꽃 성장은 잠시 멈춥니다.
9. 달빛꽃 1개를 수확하여 동쪽 섬 남쪽 고목에 전합니다. 완료 후 계속 농사와 탐험을 즐길 수 있습니다.

기본 성장 시간: 당근 12초, 달빛꽃 25초. 수확 4회마다 농사 레벨이 1 증가하며 성장 속도에 5% 보너스가 추가됩니다(최대 25%). 씨앗은 무제한이며 농장은 8칸입니다. 길목은 한 번 열면 역할을 바꾸어도 유지되어 돌아오지 못하는 상황을 방지합니다.

## 범위와 검증

Vanilla HTML / CSS / JavaScript, 720×480 Canvas, 고정 60Hz 업데이트, 충돌 검사, 클릭 경로 탐색, 상태 전환(title / playing / won)으로 구성했습니다. 픽셀 시각 요소는 코드로 직접 그립니다. 외부 에셋, 폰트, 라이브러리가 없습니다. `node --check game.js`로 문법을 검사할 수 있습니다. 브라우저 콘솔의 `mossGame.getSnapshot()`은 검증용 상태 사본을 반환하며 게임 상태를 바꾸지 않습니다.

이 버전은 핵심 반복 구조를 검증하기 위한 브라우저 프로토타입입니다. Steam 빌드, 배포, 저장, 본편 분량은 포함하지 않습니다. 페이지를 새로고침하거나 닫으면 진행이 사라집니다. 플레이 시간과 가격 가설은 실제 플레이테스트로 검증해야 합니다.
