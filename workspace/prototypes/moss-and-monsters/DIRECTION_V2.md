## 플레이어가 되고 싶은 사람

**낮에는 몬스터 친구와 식재료를 찾고, 돌아와 밭과 주방을 돌보며, 내가 만든 한 끼로 손님을 맞아 버려진 농장을 내 생활 터전으로 키우는 관리인.**

초기 버전은 몬스터를 모아 길목을 여는 짧은 퍼즐에 가까웠다. 이번 방향에서 중요한 것은 반복해서 돌아오고 싶은 거점, 작업의 결과, 다음 개선 목표다. 하루를 억지로 길게 만드는 대신 재료의 쓰임과 성장의 결과를 연결한다.

## 하루의 반복

밭을 확인하고 재배 → 오늘 필요한 재료와 동행 결정 → 섬에서 허브·목재 채집 → 주방에서 수프 조리 → 손님의 주문 납품 → 돈과 목재로 시설 개선 → 하루 기록을 보고 취침 → 변화한 농장에서 다음 날 시작.

작물은 음식 재료이면서 몬스터와 친해지는 먹이다. 수확물을 모두 팔면 영입이 늦어지고, 영입을 먼저 하면 이후 생산과 채집이 편해진다. 밭 확장과 주방 개선도 구매 순서를 고를 수 있게 한다.

몬스터는 종류별로 한 마리만 영입하고 동행은 한 마리로 제한한다. 농장 역할과 동행 역할은 동시에 적용하지 않는다. 불나방의 동행 채집 보너스와 농장의 달빛꽃 재배, 두더지의 동행 목재 보너스와 농장의 수확량 증가처럼, 한 번 길을 연 이후에도 역할 선택이 남아야 한다.

## 2차 프로토타입 범위

이 목록은 구현 목표이며 실제 통과 여부는 최신 QA.md를 따른다.

| 시스템 | 구현 규칙 |
|---|---|
| 농사·수집 | 기존 몬스터 3종, 작물 2종, 수확에 따른 농사 레벨 유지 |
| 재료 채집 | 허브·목재 채집 지점, 지점별 하루 한 번. 다음 날 재생 |
| 음식 | 당근 2개 + 허브 1개 → 수프 1개 |
| 납품 | 수프 1개 → 12G, 하루 주문 2건. 개선한 주방에서는 18G |
| 기본 판매 | 당근 1개 → 2G. 주문 한도 이후에도 수익 확보 가능 |
| 밭 확장 | 24G + 목재 3개 → 밭 8칸에서 12칸으로 증가 |
| 주방 개선 | 30G + 목재 4개 → 조리 공간 외형 변화, 수프 납품 가치 상승 |
| 하루 마감 | 수확·채집·요리·수익 기록 표시. 취침하면 날짜 증가, 자원·주문 갱신과 작물 성장 |
| 저장 | 브라우저 로컬 저장, 계속하기, 저장 실패 안내, 초기화 확인 |
| 구간 완료 | 몬스터 3종·고목 복원·두 시설 개선. 임의의 날짜까지 잠을 자야 하는 조건은 두지 않음 |

주문을 놓쳐도 벌금이나 게임 오버는 없다. 수면을 자원 리셋 버튼으로만 소비하지 않도록, 외부 시험에서는 실제 하루에 한 행동과 취침 이유를 관찰한다. 이번에는 수프 한 가지로 생산·납품 연결을 검증한다. 선택이 약하면 두 번째 요리와 서로 다른 주문을 추가하기 전에 현재 재료 수요부터 조정한다.

## 화면과 분위기

- 화면의 중심을 게임 월드에 두고 큰 소개 문구와 여백을 줄인다.
- 따뜻한 목재·천·낡은 종이와 저녁의 청록·남색을 사용한다. 참고작의 고유 캐릭터·아이콘·맵·UI를 복제하지 않는다.
- 수확물, 허브, 장작, 조리대, 납품 담당자가 월드 안에 있어 행동의 위치가 이해되어야 한다.
- 조리의 김, 밤의 실내 불빛, 늘어난 밭, 고쳐진 주방처럼 노동의 결과를 시각적으로 보여 준다.
- 현재 프로토타입은 고정 화면의 작은 섬이다. 자유로운 건축 배치, 큰 연결 맵, 풍부한 NPC 일상까지 구현했다고 표현하지 않는다.

## 1인 개발 범위 조정

생활 구조가 추가된 만큼 콘텐츠 수를 늘리는 속도는 낮춘다. 1개월은 이 순환을 온전히 보여 주는 무료 데모를 우선한다. 3개월 정식판은 몬스터 6종을 기본 상한으로 계획하고 검증·여유가 있을 때만 8종까지 늘린다. 작물은 최대 6종, 요리는 4~6개, 주요 작업 시설은 3~4개, 주변 수제 구역은 2~3개 정도가 후보 상한이다. 수치는 제작 속도와 테스트에 따라 줄인다.

1주: 바뀐 반복 구조·저장·실행 검증. 2주: 외부 플레이어 시험과 화면·조작 개선. 3~4주: 데모 범위 고정, Windows 배포 경로·저장 안정화. 5~8주: 검증한 규칙에 제한적으로 콘텐츠 추가. 9~12주: 플레이테스트, 밸런스, 버그, 상점·출시 준비에 집중한다.

지금 단계에서 NPC 연애·시간표, 계절별 농사, 전체 지형 편집, 식당 직원 경영, 복잡한 자동화, 던전 전투를 모두 추가하지 않는다. 큰 참고작의 콘텐츠 규모는 1~3개월 계획에 포함되지 않는다.

가격은 무료 데모와 소형 정식판 $7.99~9.99 가설을 유지한다. 실제 플레이 분량·완성도·외부 반응을 확인하기 전 가격이나 판매 가능성을 확정하지 않는다. Steam 공개 일정에는 온보딩과 심사, 공개 대기 기간이 별도로 필요하다. [Steamworks 온보딩](https://partner.steamgames.com/doc/gettingstarted/onboarding).

## 다음 사람 대상 테스트에서 볼 것

외부 플레이어 5명에게 조작법만 알려 주고 10~15분 정도 자유롭게 플레이하게 한다. 아래는 내부 수정 판단용 가설이며 통계적인 시장 검증이 아니다.

1. 수확물을 몬스터 먹이·음식·판매 중 어디에 쓸지 선택하는가?
2. 탐험을 떠나기 전에 필요한 재료를 스스로 말하는가?
3. 첫 납품 수익을 얻은 뒤 원하는 시설 개선을 직접 고르는가?
4. 개선한 시설을 보고 다음 날 하고 싶은 일이 생기는가?
5. 잠을 자는 이유가 단순히 목표 날짜를 넘기거나 자원을 리셋하기 위해서뿐인가?

5명 중 3명 이상이 자발적으로 다음 생산·개선 목표를 말하지 못하면 콘텐츠 추가보다 주문·재료·시설 효과의 연결을 수정한다. 자동화로 완주할 수 있다는 사실만으로 생활감과 재미가 검증되었다고 주장하지 않는다.
