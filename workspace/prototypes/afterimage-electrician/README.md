# 잔상 배선공: 6초 시간 하이스트 프로토타입

Godot 4.x용으로 제작된 **6초 시간 하이스트(6-Second Time Heist)** 액션 퍼즐 프로토타입이다.  
핵심 판타지: **"과거의 내가 다음 시도의 도구이자 때로는 장애물이 된다."**

플레이어는 6.0초(360 고정 물리 틱)의 루프 속에서 자신의 이동과 `E` 상호작용을 기록하고, 다음 루프에서 재생되는 과거 잔상과 실시간으로 협동하여 보안 시설을 돌파한다.

---

## 핵심 게임플레이 특징

1. **6.0초 콤팩트 루프 & 첫 30초 내 아하 경험**:
   - 10초 3압력판 방식에서 6초 하이스트 루프로 압축.
   - 첫 번째 방에서 단 1회의 잔상 녹화만으로 문이 열리는 협동의 쾌감을 첫 20~30초 안에 체감.
2. **E 키 상호작용 및 잔상 재생**:
   - 에너지 셀 및 금고 코어 줍기, 내려놓기, 반응로 소켓 삽입.
   - 잔상 또한 동일한 틱에 물리적 상호작용을 그대로 재현하여 시간차 아이템 릴레이 가능.
3. **4대 하이스트 요소 구현**:
   - **유인(Lure)**, **침투(Infiltrate)**, **전달(Relay)**, **동기화(Synchronize)**가 3개 마이크로 룸에 유기적으로 배치.
4. **명확한 피드백과 편의성**:
   - 즉시 재시도(`R`) 및 원하는 타이밍에 조기 루프 확정(`Space`).
   - 실패 시 명확한 원인 배너(보안 레이저 경보, 시간 초과, 전원 미공급 등).
   - 성공 시 0.5초 슬로모션, 화면 펄스, 클리어 시간 및 별점(★★★) 평가.
5. **클린 UI & F3 기술 진단 패널**:
   - 평상시에는 하이스트 타이머, 남은 시간 게이지, 명확한 임무 목표만 깔끔하게 노출.
   - 틱 카운트, 정수 비트마스크 명령, 위치 해시 무결성 등 기술 정보는 `F3` 토글 패널로 숨김.
6. **완전한 에셋 프리 프로시저럴 구현**:
   - 외부 이미지·음원·플러그인 없이 `_draw()` 벡터 렌더링 및 `AudioStreamWAV` 8비트 절차적 사운드 합성.

---

## 3대 마이크로 룸

- **룸 1: 격벽 협업 (Blast Gate Cooperation)**
  - 중앙 격벽이 탈출로를 차단. 혼자서는 문을 열고 지나가기에 시간이 부족함.
  - 잔상이 상단 제어 스위치를 누르고 있는 동안, 라이브 플레이어가 개방된 격벽을 질주 돌파.
- **룸 2: 에너지 셀 시간 전달 (Energy Cell Relay)**
  - 탈출구 반응로에 에너지 셀이 꽂혀야만 탈출문이 개방됨.
  - 잔상이 저장소에서 에너지 셀을 집어(`E`) 중앙 인계 지점에 투하(`E`), 라이브 플레이어가 이를 가로채 반응로에 삽입(`E`).
- **룸 3: 레이저 & 경비 유인 (Laser & Security Lure)**
  - 메인 통로를 차단한 치명적인 보안 레이저. 진입 시 즉시 경보 발령.
  - 잔상이 상단 기만 콘솔을 작동시켜 보안 시스템을 유인하는 사이, 라이브 플레이어가 레이저를 통과해 금고 코어를 탈취(`E`) 후 탈출.

## 조작법

- **`WASD` / 방향키**: 4방향 정수 이동 (틱당 4픽셀)
- **`E`**: 상호작용 (에너지 셀 / 금고 코어 줍기 / 놓기 / 반응로 삽입)
- **`Space` / `Enter`**:
  - 녹화 중: 현재 루프 조기 확정 후 다음 루프 침투 시작 (6초 대기 불필요)
  - 스테이지 클리어: 다음 마이크로 룸으로 진행
- **`1` / `2` / `3`**: 3개 마이크로 룸 즉시 선택 및 전환
- **`R`**: 현재 룸 즉시 초기화 및 재시도
- **`F3`**: 기술 진단 패널 토글 (해시 일치, 틱, 좌표, 커맨드 비트마스크)
- **`P` / `Tab`**: 일시정지 및 재개
- **일시정지 중 `[` / `]`**: 10틱 단위 타임라인 프리뷰 스크럽

## 기술 아키텍처 및 결정론

- **고정 물리 틱**: 60Hz 고정 틱 시뮬레이션 (`Engine.physics_ticks_per_second = 60`).
- **정수 비트마스크 명령**:
  - `CMD_UP = 1`, `CMD_DOWN = 2`, `CMD_LEFT = 4`, `CMD_RIGHT = 8`, `CMD_INTERACT = 16`
  - 부동소수점 오차나 플랫폼 차이가 발생하지 않는 순수 정수 커맨드 버퍼.
- **해시 무결성 검증**:
  - 1초(60틱)마다 위치 및 아이템 소지 상태 해시를 기록하고 재생 잔상과 대조하여 탈동기화(Desync) 실시간 감지.

## 실행 및 테스트 검증

Godot 4.2 이상에서 이 디렉터리의 `project.godot`을 연 뒤 프로젝트를 실행한다.

```powershell
godot --path prototypes/afterimage-electrician
```

> **참고**: 현재 작업 환경의 시스템 PATH에는 Godot 실행 파일이 등록되어 있지 않습니다.  
> 코드 구문 분석과 정적 분석은 Codex Python 런타임에 설치된 `gdparse`, `gdlint`, `gdformat` 도구를 통해 엄격하게 검증되었습니다.

### 정적 분석 검증 결과:
- `gdformat`: `main.gd`, `tests/smoke_test.gd` 포맷 준수
- `gdparse`: AST 파싱 성공, 구문 오류 0개
- `gdlint`: 코드 스타일 및 타입 검사 통과, 문제 0개

### 스모크 테스트 사양 (`tests/smoke_test.gd`):
Godot 바이너리가 설치된 환경에서 다음 헤드리스 명령으로 전체 검증 스위트를 실행할 수 있습니다:

```powershell
godot --headless --path prototypes/afterimage-electrician --script res://tests/smoke_test.gd
```

검증 항목 (16개 시나리오 안의 26개 assertion):
1. 씬 시작 틱 0 및 룸 1 초기화
2. 룸 1: 닫힌 격벽의 이동 차단
3. 룸 1: 잔상의 스위치 도달 및 격벽 개방
4. 룸 1: 라이브 플레이어의 탈출구 도달 및 클리어
5. 룸 2: 에너지 셀 초기 위치 확인
6. 룸 2: `E` 상호작용 셀 줍기/놓기 검증
7. 룸 2: 시간 전달(Relay) 가로채기 검증
8. 룸 2: 반응로 삽입 및 탈출문 개방
9. 룸 2: 탈출구 도달 및 클리어
10. 룸 3: 보안 레이저 감지 시 위반 실패 판정
11. 룸 3: 기만 콘솔 작동 시 레이저 비활성화(Bypass)
12. 룸 3: 금고 코어 탈취 및 탈출 클리어
13. `R` 키 즉시 룸 초기화 및 트랙 클리어
14. 스폰 좌표 원상복구
15. `F3` 진단 패널 토글 상태 보존
16. 위치 및 아이템 상태 해시의 완전한 결정론 검증
