# 6초 시간 하이스트 (6-Second Time Heist) 프로토타입 기획서

> **핵심 판타지**: *"과거의 내가 다음 시도의 도구이자 때로는 장애물이 된다."*  
> 고정 6.0초(360틱)의 루프 안에서 과거의 잔상과 실시간으로 협동하여 삼엄한 보안 시설을 돌파하는 타임 하이스트 액션 퍼즐.

---

## 1. 기획 배경 및 전환 목적

기존의 "압력판 3개 동시 점유" 기술 데모는 결정론적 녹화/재생 기술을 입증했으나, 플레이어가 10초씩 세 번 지루하게 이동한 뒤 4번째 시도에서 문을 통과해야 하므로 **첫 피드백까지 30~40초가 소요**되고 게임적 긴장감이 부족했습니다.

이를 해결하기 위해 본 프로토타입은 **"6초 시간 하이스트"**로 전면 재설계되었습니다:
1. **루프 압축**: 10초 -> **6.0초 (360틱)**로 단축하여 빠르고 긴박한 템포 제공.
2. **첫 30초 내 '아하!' 경험**: 단 1회의 과거 루프로 문을 열고 현재의 내가 통과하는 첫 번째 방을 배치.
3. **상호작용 심화**: 단순 이동을 넘어 **E 키 상호작용**(에너지 셀 줍기/놓기/꽂기, 터미널 조작)을 지원하고 잔상도 상호작용을 완벽히 재생.
4. **4대 하이스트 요소 체감**: **유인(Lure) - 침투(Infiltrate) - 전달(Relay) - 동기화(Synchronize)**가 3개의 마이크로 룸에 유기적으로 배치.
5. **명확한 게임 피드백**: 즉시 재시도(`R`), 실패 원인 배너, 성공 시 슬로모션·화면 펄스·별점(★★★) 평가.
6. **클린 UI**: 틱·해시 등 기술 데이터는 `F3` 진단 패널로 격리.

---

## 2. 핵심 게임플레이 루프 & 30초 '아하!' 곡선

```
[00:00 ~ 00:05] 방 1 진입 -> 목표 확인: "과거 잔상으로 스위치를 누르고 문을 돌파하라"
[00:06 ~ 00:12] 루프 1: 상단 스위치로 달려가 누름 -> 문 열림 -> 6초 종료 (잔상 1 확정)
[00:13 ~ 00:19] 루프 2: 과거의 잔상이 스위치로 달려가는 것을 보며, 현재의 내가 열린 문으로 질주 -> 탈출 성공!
               => 첫 20초 안에 "과거의 나와 협동하는 재미" 완벽 체감 (Aha Moment)
```

- **Space / Enter**: 6초를 다 채우지 않아도 원하는 시점에 즉시 루프 확정 가능.
- **R**: 실패를 감지하는 즉시 0.1초 만에 룸 초기화.
- **1 / 2 / 3**: 세 개의 마이크로 룸 즉시 전환.
- **F3**: 기술 진단 패널 토글 (결정론 해시, 틱, 좌표, 커맨드 비트마스크).

## 3. 3대 마이크로 룸 상세 설계

### 룸 1: 격벽 협업 (Blast Gate Infiltration)
- **요소**: **동기화(Synchronize) + 침투(Infiltrate)**
- **구조**: 방 중앙을 가로막는 대형 격벽(Blast Gate)과 상단 제어 터미널.
- **제약**: 스폰에서 터미널을 들렀다가 문으로 가면 380틱이 걸려 360틱(6초) 내 통과 불가능.
- **해결책**:
  1. 루프 1 (잔상): 상단 터미널로 이동해 게이트 개방 스위치를 점유.
  2. 루프 2 (라이브): 과거 잔상이 게이트를 열어주는 타이밍에 맞춰 하단 직선 통로로 질주하여 탈출구 돌파.
- **과거의 나**: 든든한 문지기 조력자.

### 룸 2: 에너지 셀 시간 전달 (Energy Cell Relay)
- **요소**: **전달(Relay) + 동기화(Synchronize)**
- **구조**: 좌측 저장소의 에너지 셀, 중앙 격벽, 우측 탈출구 앞 반응로(Reactor Socket).
- **제약**: 혼자서 셀을 줍고 우회 통로를 돌아 반응로에 꽂으려면 400틱 이상 소요.
- **해결책**:
  1. 루프 1 (잔상): 저장소로 달려가 에너지 셀을 집고(`E`), 중앙 인계 지점(x=560)까지 운반한 뒤 투하(`E`).
  2. 루프 2 (라이브): 곧바로 중앙 인계 지점으로 직행. 과거 잔상이 셀을 내려놓는 순간 가로채서(`E`) 반응로 소켓에 삽입(`E`) -> 탈출 격벽 해제 -> 탈출!
- **과거의 나**: 셀을 운반해주는 시간 릴레이 파트너. (실수로 길목에 서 있으면 충돌 장애물로 작용)

### 룸 3: 레이저 & 경비 유인 (Laser & Guard Lure)
- **요소**: **유인(Lure) + 침투(Infiltrate) + 탈취(Transfer)**
- **구조**: 메인 금고 복도를 지키는 상시 보안 레이저망(Security Laser Grid)과 상단 기만 센서(Decoy Console), 심층부의 금고 코어(Vault Core).
- **제약**: 보안 레이저를 그대로 건너면 경보가 발령되어 즉시 룸 실패.
- **해결책**:
  1. 루프 1 (잔상): 상단 기만 콘솔로 돌진해 조작(`E`). 보안 드론/레이저가 상단으로 시선을 돌리며 메인 복도 레이저가 3초간 비활성화.
  2. 루프 2 (라이브): 레이저가 해제된 틈을 타 중앙 복도를 전력 질주, 금고 코어를 탈취(`E`)한 뒤 탈출 지점으로 이탈!
- **과거의 나**: 보안 시스템을 도맡아 끌어당기는 미끼(Bait).

## 4. 결정론적 시스템 아키텍처

```
+-------------------------------------------------------------------+
|                        60Hz Fixed Tick Engine                     |
+-------------------------------------------------------------------+
   |                                                              |
[Live Player Input]                                      [Ghost Replay]
   | (Bitmask Integer: 0b00010001)                                | (Read from Track)
   | - Bit 0..3: DIR (Up/Down/Left/Right)                         |
   | - Bit 4: INTERACT (E key)                                    |
   v                                                              v
[Deterministic Move & Collision]                         [Deterministic Move]
   v                                                              v
[Interact Logic: Pick/Drop/Socket]                       [Interact Replay: Pick/Drop]
   |                                                              |
   +------------------------------+-------------------------------+
                                  |
                                  v
                    [Hash State Sample (Every 1s)]
                       - Position, Held Item, Target
                       - Compare -> Verify Zero Desync
```

### 정수 비트마스크 명령 체계
- `CMD_UP = 1`, `CMD_DOWN = 2`, `CMD_LEFT = 4`, `CMD_RIGHT = 8`, `CMD_INTERACT = 16`
- 부동소수점 오차가 일절 발생하지 않는 순수 정수 기반 시뮬레이션.
- 상호작용(`E`) 또한 비트마스크에 기록되어 잔상이 물리적으로 동일한 틱에 아이템을 줍고 놓음.

## 5. 피드백 및 연출 (Zero-Asset Procedural Polish)

- **슬로모션 & 화면 펄스**: 스테이지 클리어 순간 0.5초간 0.35배속 슬로모션 및 골드/시안 펄스 방출.
- **명확한 목표 & 실패 원인 배너**:
  - 목표: 상단 고정 헤더에 방별 임무 표시.
  - 실패: 레이저 감지, 6초 타임아웃, 전원 미공급 등 원인을 적색 경보 배너로 명시.
- **하이스트 평가 시스템**: 클리어 시간과 루프 시도 횟수에 따라 ★★★ / ★★☆ / ★☆☆ 별점 제공.
- **프로시저럴 8비트 오디오**: 외부 음원 없이 GDScript `AudioStreamWAV`로 상호작용 비프, 레이저 경보음, 승리 팡파레를 합성.
