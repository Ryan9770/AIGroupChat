# 키네틱 절개 탈출 (Kinetic Breach Runner / 가칭 절개항해)

> 기획 문서: `docs/KINETIC_BREACH_RUNNER_PROTOTYPE.md` 기반 구현  
> 장르: 2D 물리 경로 편집 액션 (Kinetic Path-Editing Action)  
> 플레이 플랫폼: 웹 브라우저 (HTML5 Canvas + Web Audio API)

---

## 1. 개요와 플레이어 판타지

**"고압 폐쇄 구역을 절개해 자원과 추진 반동을 얻고, 자신이 만든 누출 압력을 봉합하며 표본을 확보해 귀환하는 2D 물리 경로 편집 액션"**

플레이어는 위험한 폐쇄 구역에서 물리 법칙을 도구로 사용하는 기술 탐험가입니다. 벽을 부수는 것이 아니라 필요한 만큼 절개하고, 발생한 압력을 추진력으로 활용하며, 감당할 수 없는 누출은 나노 봉합재로 차단합니다.

---

## 2. 핵심 게임플레이 루프

### 30초 코어 루프
1. **취약 재질 및 압력 방향 식별**:
   - **청록색 균열벽 (Vulnerable Seam)**: 절개 가능, 절개 시 누출 발생, 봉합 가능
   - **주황색 결정벽 (Unsealable Volatile Seam)**: 절개 가능하나 절대 봉합할 수 없음 (고위험 고보상 지름길)
   - **감압 밸브 (Pressure Valve)**: 절개 시 방 전체 압력 -20% 즉시 완화
2. **절개 (Kinetic Breach)**:
   - 마우스로 조준 후 `좌클릭` 또는 `Space`
   - 조준선 반대 방향으로 **강력한 키네틱 반동 추진력(Recoil Impulse)**이 발생하여 플레이어를 튕겨냄
   - 벽면이 파단되며 픽셀 파편과 함께 **고압 가스/에너지 제트 누출구(Breach Rupture)** 생성
3. **누출 제어 (Nanite Seal)**:
   - 활성화된 누출구 근처에서 `우클릭` 또는 `Shift`
   - 나노 봉합재(Sealant)를 소비하여 누출구를 급속 폼으로 밀폐
   - 누출 차단 시 구역 내 압력 상승 완화 및 보너스 감압
4. **자율적 정산 (Decompression Airlock)**:
   - 감압실 에어락에 진입하여 `E` 키로 콘솔 조작
   - **표본 영구 사출 (Eject & Bank)**: 소지 중인 미사출 표본을 100% 안전하게 기지로 전송 (실패 시 미사출 자원만 손실)
   - **횡적 슈트 강화**: 사출한 표본 자원으로 4종의 고유 모듈 장착
   - **탐사 지속 여부 결정**: "귀환 성공(런 완료)" vs "다음 심도 구역 진입(더 높은 위험과 보상)"

## 3. 압력 단계 시스템 (Chamber Pressure)

구역 내 배경 압력과 열려 있는 모든 누출구의 누출률이 합산되어 실시간으로 압력이 상승합니다:

| 압력 단계 | 수치 | 시각 및 음향 연출 | 게임플레이 영향 |
|---|---|---|---|
| **SAFE (안정)** | 0% ~ 39% | 청록색 HUD, 안정된 저음 앰비언트 | 정상 시야, 표준 기동 |
| **WARNING (경고)** | 40% ~ 74% | 주황색 HUD, 반응로 웅웅거림 고조 | 공기 난기류 발생 (플레이어 이동에 미세 외력 적용) |
| **CRITICAL (위기)** | 75% ~ 99% | 붉은색 화면 플래시, 고주파 사이렌 펄스 | 고속 가스 분출, 시야 왜곡 및 긴장감 극대화 |
| **COLLAPSE (붕괴 카운트)** | 100% 도달 | 10초 비상 격벽 붕괴 카운트다운 가동 | 10초 내 누출을 봉합하거나 밸브를 열어 압력을 내리지 못하면 즉사! |

## 4. 조작 가이드

| 조작키 | 동작 | 설명 |
|---|---|---|
| `W` `A` `S` `D` / 방향키 | 추진 이동 | 미세 관성 제어 (우주 슈트 유동) |
| `마우스 이동` | 조준 | 절개선 레이저 및 반동 예상 궤적 표시 |
| `마우스 좌클릭` / `Space` / `J` | **절개 및 반동 추진** | 전방 벽면 파단 및 후방 급속 반동 킥 |
| `마우스 우클릭` / `Shift` / `K` | **나노 봉합** | 봉합재 1소모, 주변 누출구 급속 밀폐 |
| `E` | 에어락 상호작용 | 감압실 콘솔 진입 (사출, 강화, 진행) |
| `F3` 또는 `Tab` | 기술 진단 패널 | FPS, 물리 좌표, 틱 타임, 누출률 노출 |

## 5. 실행 방법

별도의 설치나 빌드 과정 없이, 브라우저에서 `index.html` 파일을 직접 열면 즉시 플레이할 수 있습니다.

### 방법 1: 브라우저에서 직접 파일 열기
- `kinetic-breach-runner/index.html` 더블 클릭 또는 크롬/엣지 브라우저로 드래그 앤 드롭

### 방법 2: 로컬 웹 서버 실행 (권장)
```powershell
# 프로젝트 루트에서
npx serve kinetic-breach-runner -p 3000
```
브라우저에서 `http://localhost:3000` 접속

## 6. 코드 아키텍처

- `index.html`: 반응형 캔버스, CRT 스캔라인, HUD 오버레이, 에어락/가이드/결과 모달
- `style.css`: 사이버펑크 SF 테마 스타일, 경보 플래시 애니메이션, 가독성 높은 계기판
- `audio.js`: 순수 Web Audio API 절차적 사운드 신시사이저 (절개음, 반동 붐, 밸브 분출음, 누출 앰비언트 드론, 사이렌)
- `game.js`:
  - `PressureGraph`: 논리 압력 그래프, 누출률 적분, 붕괴 카운트다운
  - `Player`: 2D 충돌 물리, 키네틱 반동 충격량 벡터, 레이저 조준기 및 궤적 프리뷰
  - `Breach`: 누출구 위치, 법선 벡터, 제트 파티클 분출 및 위험 판정
  - `Camera`: 픽셀 퍼펙트 추적, 충격 트라우마 기반 화면 흔들림, 히트스탑(마이크로 프리즈)
  - `Sectors`: 4개 구역(저압 시험장 → 가압 도관 → 원자로 격리 → 심층 코어) 레벨 생성
