# 픽셀 관성 인쇄 (Pixel Momentum Print)

> 기획 문서: `docs/PIXEL_MOMENTUM_PRINT_DISCUSSION_RESULT.md` 기반 구현  
> 장르: 운동량 편집 액션 퍼즐 (Momentum-Editing Action Puzzle)  
> 플레이 플랫폼: 웹 브라우저 (HTML5 Canvas + Web Audio API)

---

## 1. 개요와 플레이어 판타지

**"움직이는 물체의 운동 벡터를 픽셀 띠로 수집한 뒤 플레이어, 사물, 기믹에 인쇄하여 운동량 보존과 반작용으로 이동 규칙을 재배선하는 2D 액션 퍼즐"**

플레이어는 실험 구역 내의 피스톤, 드론, 진자 등에서 8방향 3단계 세기로 양자화된 관성 띠(Momentum Stamp)를 포획하고, 슬로모션 시간 팽창 상태에서 궤적을 예측한 뒤 사물이나 플레이어 자신에게 인쇄하여 퍼즐을 해결합니다.

---

## 2. 30초 코어 루프

1. **궤적과 위험 관찰**: 움직이는 관성원(피스톤, 드론, 진자)의 이동 속도와 주기를 파악합니다.
2. **관성 수집 (Extract)**: 관성원에 접근하여 `E` 키를 누르면 현재의 순간 운동 벡터가 8방향(`→`, `↘`, `↓`, `↙`, `←`, `↖`, `↑`, `↗`)과 3단계 세기(약/중/강)로 양자화되어 슬롯에 저장됩니다.
3. **슬로모션 조준 (Slow-Mo Aim)**: `우클릭 유지` 또는 `Space` 키로 시간을 **0.2배속**으로 감속시키고, 대상 지정 시 예상 비행 궤적 및 충돌 경로를 점선으로 미리 확인합니다.
4. **인쇄 (Print)**: `좌클릭`으로 사물(상자, 구체) 또는 플레이어에게 관성을 인쇄하여 고속 추진시킵니다.
5. **편향 및 연쇄 반응 (Deflection & Chains)**: 45도 반사판(Bumper)을 통한 궤적 굴절, 충격 격벽 분쇄, 바닥 압력 스위치 활성화, 화물 도크 안착을 달성합니다.

---

## 3. 5대 시험실 (Chambers)

1. **제1실: 관성 추출과 도약**: 피스톤에서 우측/좌측 운동량을 추출해 플레이어 슈트에 인쇄, 공허 균열을 도약 탈출.
2. **제2실: 화물 수송과 충격 격벽**: 고속 드론에서 강한 운동량을 추출해 무거운 상자에 인쇄, 균열벽을 부수고 스위치 가동.
3. **제3실: 연쇄 반작용 편향**: 45도 반사판(Bumper)을 통해 궤적을 90도로 꺾어 직접 조준할 수 없는 스위치 타격.
4. **제4실: 정밀 화물 안착 챌린지**: 공허 구덩이에 빠뜨리지 않고 황금 코어 화물을 우측 화물 도크에 정밀 안착.
5. **제5실: 운동량 연쇄 마스터**: 다중 관성원과 상자, 반작용 밀림을 종합적으로 활용해 이중 보안 격벽 해제.

---

## 4. 조작 가이드

| 조작키 | 동작 | 설명 |
|---|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 | 플레이어 2D 기본 이동 |
| `1` `2` `3` / `Q` / 휠 스크롤 | 슬롯 전환 | 3개의 관성 저장 슬롯 전환 |
| `E` / 관성원 근처 클릭 | **관성 수집 (Extract)** | 관성원 속도를 8방향 3단계 벡터로 포획 |
| `우클릭 유지` / `Space` | **슬로모션 조준** | 0.2배속 시간 팽창 + 예상 궤적 점선 프리뷰 |
| `좌클릭` | **관성 인쇄 (Print)** | 조준 대상(상자 또는 플레이어)에 벡터 부여 |
| `R` | 레벨 재시도 | 현재 시험실 즉각 리셋 |
| `F3` / `Tab` | 기술 진단 모드 | FPS, 시간 배율, 좌표, 슬롯 상태 노출 |

## 5. 실행 방법

- **직접 실행**: `pixel-momentum-print/index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다.
- **로컬 서버 실행**:
  ```powershell
  npx serve pixel-momentum-print -p 3001
  ```
