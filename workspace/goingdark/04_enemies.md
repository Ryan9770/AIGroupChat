## 1. 설계 원칙

1. **모든 몹은 '삼켜진 것'이다** — 각 몹은 몰락의 밤 이전 에르가비아의 신분을 가진다.
   행동 패턴에 생전의 습관이 남는다(병정은 보고를 올리고, 골렘은 여전히 보물을 지킨다).
2. **몹은 시선의 하청업체다** — 시선 구간이 몹 AI를 바꾼다(§4). 어둠=적의 증강이 아니라
   '내가 더 눈에 띄는 것'.
3. **전투는 소리를 남긴다** — 모든 몹은 처치·피격 시 소음을 만들고, 소음은 주변 잔재를 부른다.
   전투의 진짜 비용은 HP가 아니라 **다음 무리를 불러오는 것**이다.
4. **몹 3종칙** — 모든 몹은 (a) 접근 신호 (b) 공격 전조 (c) 제압기 중 최소 2종을 가져
   플레이어 기량(구르기 타이밍)으로 대응 가능해야 한다.

## 2. 일반 몹

### 2.1 해골병정 (Skeleton Grenadier) — 원거리 견제형

| 항목 | 내용 |
|---|---|
| 세계관 | 몰락의 밤에 삼켜진 국경 수비대 잔재. 생전 명령 "전방 확인 후 보고"에 잠김 |
| 등장 | 1~4층 (1층 3스폰 중심, 4층 '왕실 호위' 변형) |
| HP / 피해 | HP 60 / 석궁 1발 12(관통 없음, 탄창 3발·재장전 2.4초) |
| 사거리 / 탐지 | 14m / 기본 12m — 시선 31+ 시 15.6m(+30%) |
| 이동 | 2.8 m/s. 피격 시 후방 4m 후퇴 사격 |
| 처치 보상 | 일반 확정 + 언코먼 8% |

**행동 패턴 (3종칙 대응)**
- (a) 접근 신호: 발견 시 금속 발구름 소리 + "전방… 확인" 유언 재생(0.5초) — 사격 전 유일한 선제공 기회
- (b) 공격 전조: 조준 레이더 없음. 대신 0.7초간 석궁 수평 고정(고개 포함) — 측면 회피 용이
- (c) 제압기: 없음. 단 3연사 후 재장전 2.4초가 유일한 진입 창
- 특이: 시체에서 '병장의 반지' 퀘스트 드롭(1막). 처치 시 "보고를… 왕에게…" 소멸 대사

**카운터**: 구르기 접근 → 근접 **3~4히트**(1.65~2.2초)로 처치. 최소 롤(18)이 세 번 뜨면 54라 4히트가 필요하다. 전력질주 시 탐지 사거리에서 쉽게 벗어남.
**설계 의도**: 초보의 '소리 관리' 교육. 1층에서는 단독, 3층 이후 2인 사격조로 등장.

### 2.2 심연충 (Abyss Mite) — 군집 근접형

| 항목 | 내용 |
|---|---|
| 세계관 | 위액에 잠긴 시체가 부패하며 끓어오른 '소화 효소 덩어리'. 삼켜진 자의 손톱·이가 껍질 |
| 등장 | 2층 최초 등장 ~ 5층(친위 군집). 3층 전당 군락지대 상시 |
| HP / 피해 | HP 30 / 물어뜯기 8(1.1초 간격, 치명타 없음) |
| 군집 | 3마리 1조. 조장 1마리 사망 시 잔여 개체 4초간 폭주(이동 5.0 m/s) |
| 탐지 | 시야 8m + **청각 특화**: 구르기(큰 소리)에 즉시 반응 — 20m 내 조그 소리 방향 집결 |

**행동 패턴**
- (a) 접근 신호: 군집 특유의 딱딱 소리(2초 전). 벽을 기어 다님
- (b) 공격 전조: 도약 전 0.4초 몸 낮춤 — 구르기 1회로 회피 가능
- (c) 제압기: 폭주 돌진(피해 없음, 넘어뜨림 0.8초) — 폭주 시에만
- 특이: 조장/잔여 구분은 머리 껍질 색(짙음=조장). 조장 우선 처리가 정답

**카운터**: 근접 광역기 없음 — 구르기 무적으로 폭주 흘려보내고 반격. 화염 계열 없음(초기 밸런스).
**설계 의도**: '군중 속 고립' 공포. 처치보다 회피가 이득인 첫 몹 — 약탈 게임의 도주 유혹 교육.
시선 91에서 붙는 **수색대 추격 조**를 심연충 군락 한복판으로 끌고 가면 잔재끼리 뒤엉켜 추격이 끊긴다 — 도주 기술로서 의도된 메타.

### 2.3 수호 골렘 (Hoard Golem) — 보물방 고정형

| 항목 | 내용 |
|---|---|
| 세계관 | 왕국이 보물을 지키려 부은 청동 병기. 주인이 소멸한 뒤에도 '지키기만' 계속한다 |
| 등장 | 3층 성물 보관방, 4층 회랑 경비실 — **보물방 진입 시에만 기동** |
| HP / 피해 | HP 220 / 내려찍기 30(판정 반경 2.2m, 전조 1.1초), 회전 휩쓸기 22(전조 1.4초) |
| 이동 | 2.0 m/s. **보물방 반경 8m 이탈 불가**(사슬 연출) |
| 상태 | 경갑 — 근접 피해 15% 감소. 구르기 무적 회피는 유효 |

**행동 패턴**
- (a) 접근 신호: 보물 상자 상호작용 시작과 동시에 기동(눈의 청동 불) — 보물과 골렘 중 하나만 가능
- (b) 공격 전조: 두 전조 모두 길고 과장 — 정면 회피는 쉽다. 단 전조 중에도 이동 봉쇄는 유효
- (c) 제압기: 회전 휩쓸기 2연속 — 2회차는 구르기 쿨(1.2초) 타이밍 역이용 설계
- 특이: 처치 시 보물방 드롭 등급 1단계 상승(일반→언코먼 등). 단 처치 전에도 보물 탈취는 가능(도주 루트)

**카운터**: 기둥 지형 이용 — 골렘은 우회 경로 고정. 2인 플레이 시 1인 유인·1인 약탈 가능(듀오 모드 핵심 전술).
**설계 의도**: '보물 = 전투 강요' 장치. 전투 승리가 아니라 '언제 싸우고 언제 훔칠까'를 묻는 퍼즐 몹.

### 2.4 왕실 호위 잔재 (Royal Remnant) — 4층 강화형 (V1.5 권장, MVP는 해골병정 강화 스킨)

| 항목 | 내용 |
|---|---|
| 세계관 | 4층 회랑에 남은 왕실 호위대. 생전 무술의 잔상이 자동 재생되는 '녹화된 시체' |
| HP / 피해 | HP 90 / 검격 16(0.7초 간격), 방패 밀치기(넘어뜨림 0.8초) |
| 탐지 | 10m. **소음 무관 시야 전용** — 소리 유인 무효 |
| 처치 보상 | 언코먼 확정 + 레어 6% |

**행동 패턴**: 검+방패 가드 — 정면 공격 40% 감소. 후방 회피 후 기습 유도형.
**설계 의도**: 4층 순찰 밀집 층에서 '정면 싸움은 손해'를 가르치는 몹. 가드-백스텝 원리가 그대로 감시자 P1 검술 대응으로 이어져 **보스전 예습**이 된다.

## 3. 보스 — '감시자 (The Warden)'

### 3.1 기본 정보

| 항목 | 내용 |
|---|---|
| 정체 | 잿빛 등 최고위 봉인 집행관. EG 287에 5층에서 시선 100 도달, 아비그라와 융합(세계관 §4 타임라인) |
| 등장 | 5층 어좌의 방 외벽 '집행의 방' — 4막 스토리 후 상시 조우 가능 |
| HP | **1,600** (3페이즈: 1600~1100 / 1100~550 / 550~0) |
| 처치 보상 | **에픽 '심연의 심장' 45% + 레어 확정 3** (코어 명세 상속) — 확정 드롭은 경제를 붕괴시켜 v2에서 확률화 |
| 리스폰 | 처치 후 **실시간 12시간** (세션당 1회 조우) — 반복 파밍 차단 |
| 조우 조건 | 레어 조각 3 헌납 후 승강구 개방(퀘스트 4막). 세레나 동행 여부가 연출 분기 |

### 3.2 페이즈 상세

**P1 (1600~1100) — '집행관'**
- 공격: 봉인 집행관 검술. 베기 24(전조 0.8초), 찌르기 30(전조 1.0초, 직선 돌진 6m)
- 이동 3.2 m/s. 구르기 회피 정석으로 대응 가능한 '공정한' 페이즈
- 세레나 동행 시 원거리 지원(1발 10) — 어그로 분산 없음, 감시자는 세레나를 우선 무시(교리)
- 전환 연출: 팔이 녹기 시작 — "기억은 남았습니까"(세레나 대사, `trg: boss_guardian_engage`)

**P2 (1100~550) — '융합'**
- 녹아내린 오른팔이 위액 창으로 변형. 공격 범위 확대: 창 찔러 관통 34(전조 0.9초, 관통 지형 무시), 위액 도말(바닥 잔류 5초, 초당 6)
- 이동 2.6 m/s로 감소 — 대신 공격 리듬 불규칙화(0.8~1.6초 랜덤 간격)
- 신규 기제: **위액 파도** — 15초마다 방 한쪽에서 낮은 파도(점프 또는 구르기 회피, 피격 시 20+ 이동속도 -20% 3초)
- 세레나: "기억은 남지 않았군요. 그렇다면 남긴 것은 제가 거두겠습니다." — 지원 사격 중단, 봉인 의식 시작(플레이어가 막을 필요 없음, 90초 카운트 연출)

**P3 (550~0) — '시선'**
- 완전 융합. 검술 폐기, 아비그라의 기관이 됨:
  - **증원 방송**: 15초마다 감시자가 '본' 위치로 잔재 증원 2기(해골병정 또는 심연충 조)를 불러들인다 — 세계관 §1.4 '강한 자를 모아 소화하는 면역 반응'의 국소 발현. 방을 비우며 싸울 수 없게 만드는 장치
  - 공격: 위액 광역 분사(반경 4m, 28, 전조 1.2초), 시선 빔(단일 대상 마크 2초 후 35 — 구르기 회피)
  - 이동 불가(고정 포대화) — 도주·은폐 플레이 가능. 단 보물(에픽)은 시체에서 나오므로 최후엔 처치 필요
- 전환 대사: "이것이 당신의 기도였습니까. 그렇다면 제 답은 검입니다."(세레나)
- 처치 연출: 세레나 최후 일격 참여 → "평안하십시오." 드롭: 심장이 박동하는 육괴에서 레어 확정 3 토출, 에픽 '심연의 심장'은 45%

### 3.3 교전 회피 분기 (퀘스트 4막 연동)

- 조건: 종단 신임 高(높음) + 2막 A(세레나) 경로 클리어
- 진행: P1 진입 전 세레나가 "예의를 갖추어 죽이는 것" 외에 "대화로 마지막 봉인을 맡기는 것" 제안
- 감시자는 3문장만 발화(녹음된 집행관 규격 보고 — 인격은 이미 없음이 확인됨) 후 스스로 어좌 외벽의 봉인 못에 몸을 넣어 봉인 재개
- **보상 동일 보장**(에픽 45%+레어 확정 3 — 봉인 못이 토해냄). 단 회수까지 60초 연출(조수 타이밍과 경쟁)
- 분기 결과: 세레나 생존(회피) vs 세레나 이탈 가능(처치) — 7막 B엔딩 조건에 반영

### 3.4 밸런스 노트
- 솔로 예상 처치 시간(실효 DPS 13 기준): P1 500HP 38초 / P2 550HP 42초 / P3 550HP 42초 — **총 약 122초**.
  듀오는 HP ×1.6(2,560)이나 DPS도 ×2라 체감 시간 유사(약 98초).
- P3는 보스가 고정 포대가 되어 회피 난도가 급락하는 대신, **증원 2기/15초**가 압박을 이어받는다.
  증원 누적이 4기를 넘으면 도주가 정답이 되도록 스폰 상한을 6기로 둔다
- 위액 도말·파도는 구르기 쿨 1.2초를 초과하는 연속 요구 금지(공격자 우위 원칙)

## 4. 시선 구간 × 몹 AI 매트릭스

| 시선 구간 | 해골병정 | 심연충 | 수호 골렘 | 감시자 |
|---|---|---|---|---|
| 0~30 안전 | 탐지 12m | 시야 8m | 정상 | 정상 |
| 31~60 | 탐지 15.6m (+30%) | 집결 반경 20m→26m | 정상 | 정상 |
| 61~90 | 탐지 +30% 유지 + **속삭임 옐라**: 가짜 발소리 방향으로 병정 1기 이탈(플레이어 위치 오인) | 폭주 확률 2배 | 기동 전조 1.1→0.9초(던전이 재촉) | P3 증원 주기 15→10초 |
| 91~100 수색대 | 전 층 병정이 30초 간격 최후 목격지 수색 + 60초마다 추격 조 1개(병정 2) 추가 스폰 | 상시 폭주 | — | 증원 상시(주기 10초) |

- 시선 효과는 '적 강화'가 아니라 '탐지·혼란·증원' 계열 — 맞으면 이길 수 있는데 **끊이지 않게** 되는 방향(코어 명세 '리스크 메트로놈' 유지).
- PvE 전환으로 시선 91의 대가가 'PvP 표적'에서 '수색대 추격'으로 바뀌었다. 압박의 종류는 달라졌지만 **탈출 강제력은 동일**하게 유지하는 것이 튜닝 목표.

## 5. 층별 스폰 구성표 (코어 밀도 상속: 1층 3 → 5층 9+보스)

- 리스폰: 처치 후 90초, 단 시선 91+ 구간은 60초(던전의 소화 재촉).
- 스폰 위치는 고정 스팟 + 랜덤 오프셋(±3m) — 암기 플레이와 적응 플레이 공존.
