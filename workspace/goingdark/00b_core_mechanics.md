# 00b. 코어 메커닉스 명세 — 『Revenant Run』

> **v2 — PvE 전환판.** 본 문서가 전 문서의 기준값 원본이다.
> PvPvE에서 PvE 코옵으로의 전환 내역과 폐기된 PvP 설계는 `10_pve_revision.md` 참조.

## 컨셉 (1~2줄)
저주받은 심연 던전에 침입해 보물을 약탈하고, 살아서 탈출하는 **PvE 회수형 던전 크롤러**.
**"가져나와야만 내 것이다."** — 사망 시 전 로스트, 탈출 시 전 보유.

## 핵심 루프 (한 문장)
던전에 침입해(행동) 방·보물·잔재를 탐색/전투로 뚫고(피드백) 탈출 게이트에 도달하면 약탈품이 영구 보유되고, 죽으면 전부 잃는다(보상/위협).

## 파티 구조 (PvE 전환의 핵심)
- **1~3인 파티 전용 인스턴스.** 한 세션에 한 파티만 진입한다 — 난입도, 적대 플레이어도 없다.
- 인원 스케일링: 몹 HP ×1.0 / ×1.6 / ×2.2, 스폰 수 ×1.0 / ×1.3 / ×1.6 (솔로/듀오/트리오)
- **인스턴스 = 스토리 결정론 확보**: NPC 동행·보스 조우·엔딩 선택이 타 플레이어와 경합하지 않는다.
  (PvPvE 시절 미해결이던 '공유 세션에서 어떻게 단일 엔딩을 고르는가' 문제가 구조적으로 소멸)
- 사망 시 시체는 그 자리에 남고 **파티원만 60초 내 회수 가능** — 이후 위액에 융합되어 소멸.
  전멸 또는 솔로 사망 = 전 로스트. **리스크의 가격은 그대로다.**
- 리스크 공백 보완: PvP가 빠진 자리를 **조수 타이머 · 시선 수색대 · 소리 관리**가 대체한다.

## 세션 구조
| 단계 | 시간 | tension |
|---|---|---|
| 준비 (거점) | 2~3분 | 낮음 — 장비 반입 선택, 퀘스트 수주 |
| 탐색 (1~3층) | 8~11분 | 중립 — 약탈, 소리 관리 |
| 심층 (4~5층) | 7~10분 | 높음 — 순찰 밀집, 고가치 보물 |
| 귀환 갈림길 | 3~5분 | 최고 — 탈출 vs 추가 약탈 도박 |

- 던전 체류: **18~26분** / 세션 목표 플레이타임: **20~28분** (하드 컷 30분)
- 위 3구간 합계가 조수 3단계(22/27/30분)와 1:1로 대응하도록 잡았다. **35분 세션은 존재하지 않는다.**

## 조작 (키보드/마우스)
| 입력 | 동작 |
|---|---|
| WASD | 이동 (보행 4.0 m/s, 습격 시전 중 2.2 m/s) |
| Shift | 전력질주 (6.5 m/s, 스태미나 100 → 22/s 소모, 15초 지속) |
| 좌클릭 | 근접 공격 (1히트 0.55초, 사거리 1.6m, 피해 18~24) |
| 우클릭 | 방패 가드 (피해 70% 감소, 이동속도 -40%) |
| Q | **성수 등불** (MVP 공용 스킬 — 3초간 반경 5m 시선 상승 정지 + 몹 탐지 -30%, 쿨 18초) |
| E | 상호작용 (문·상자·시체회수·게이트) |
| F | 탈출 신호 (게이트 충전 8초 — 전 층 경보) |
| Tab | 인벤토리 (8슬롯, 열면 이동속도 -60%, 소리 발생) |
| Space | 구르기 (무적 0.3초, 쿨 1.2초, 소리 큼) |

- **원거리 무기 없음** (MVP). 플레이어 공격 수단은 근접 1종 + Q 유틸뿐 — 석궁·화살은 몹 전용이며 소모품 목록에도 없다.
- 캐릭터별 고유 스킬은 V2 클래스 시스템에서 도입. MVP는 Q 공용 1종으로 고정.

## 플레이어 상태
- HP 100 / 스태미나 100 / 시선(저주) 수치 0~100
- 사망: 인벤토리 전량 시체로 드롭, 거점 부활 (장비도 로스트 — 반입 시점에만 소유권)

## 전투 기준 수치 (모든 HP·처치시간 산출의 원본)
- 이론 근접 DPS: 평균 21 피해 ÷ 0.55초 = **38.2 DPS**
- **실효 DPS ≈ 13** (전조 회피·거리 재조정 포함 실접촉률 35% 가정). 모든 처치 시간은 이 값 기준.
- 몹 처치 시간 = HP ÷ 13 (솔로 기준). 듀오 ÷2 아님 — 인원 스케일링(HP ×1.6)이 상쇄해 체감 시간은 유사.

| 대상 | HP | 솔로 목표 처치 시간 |
|---|---|---|
| 심연충 | 30 | 2.3초 (근접 밀착 시 2히트) |
| 해골병정 | 60 | 4.6초 (밀착 시 **3~4히트** — 최소 롤 18×3=54로는 부족) |
| 수호 골렘 | 220 (경갑 15%↓) | 약 20초 |
| 보스 하르트 | 1,000 | 약 75초 |
| 보스 감시자 | 1,600 | 약 120초 |
| 보스 삼킨 왕 | 2,400 | 약 180초 |

## 약탈 시스템
| 등급 | 예 | 평균 가치 | 드롭률 |
|---|---|---|---|
| 일반 | 고철·약초 | 10~30 | 60% |
| 언코먼 | 강화 무기·포션 | 50~120 | 28% |
| 레어 | 유물 조각 | 200~500 | 10% |
| 에픽 | 심연의 심장 | 1,000~2,500 | 2% (보스/암흑방) |
- 슬롯 8개 제한 → 가치 밀도 선택이 곧 전략
- 무거운 아이템(2슬롯)은 이동속도 -10%

## 전투 (PvE)
- PvE 몹: 해골병정(원거리 1발 12), 심연충(군집 3마리, 1마리 HP 30), 수호 골렘(보물방, HP 220)
- 층별 몹 밀도: 1층 낮음(3스폰) → 5층 높음(9스폰)+보스 1
- **소리가 곧 위협**: 공격 피격·구르기·인벤토리 개방은 소음을 만들고, 소음은 반경 20~26m 잔재를 끌어온다.
  PvP가 없으므로 '발각의 대가'는 전부 몹 증원으로 지불된다.
- 보스 '감시자': HP **1,600**, 3페이즈 (1600~1100 / 1100~550 / 550~0)

## 탈출 규칙 (게임의 심장)
1. 탈출 게이트는 각 층 2곳, **세션 18분부터 개방** (그 전엔 진입 게이트만)
2. 게이트 충전 8초 — 충전 중 피격 시 초기화. **충전 시작 시 전 층 경보**: 반경 40m 내 잔재 전원이 게이트로 집결
3. **심연 조수(Tide)** — 3단계 램프업:

| 단계 | 시점 | 피해 | 의미 |
|---|---|---|---|
| 1차 | 22분 | 10초당 HP 3 | 압박 — 붕대로 버티며 퇴각 가능 (5분 누적 90) |
| 2차 | 27분 | 초당 HP 3 | 퇴각 신호 — 무보정 생존 33초 |
| 3차 | 30분 | 초당 HP 10 | 하드 컷 — 10초 |

4. 미탈출 사망 = 전 로스트. 이것만이 리스크의 진짜 가격.

## 시선(저주) 시스템 — 던전 내 리스크 메트로놈
- 어둠에 머무는 시간·유물 직접 소지 시 시선 상승
- **0~30** 안전
- **31~60** 몹 탐지거리 +30%
- **61~90** 유물 속삭임(가짜 지도), 몹 기동 전조 단축
- **91~100 '수색대'** — 전 층 잔재가 30초마다 플레이어 최후 목격지로 집결하고, 60초마다 추격 조(해골병정 2)가 추가 스폰된다. 동시에 파티원 전원에게 해당 플레이어 위치가 표시된다(구조용).
  ※ PvPvE 시절의 '전 플레이어에게 위치 노출'을 PvE 추격 압박으로 치환한 항목.
- 시선 감소: 성수병(상점 **40골드** — 고정), 빛의 제단(던전 내 2곳), Q 성수 등불(상승 정지만)

## 거점 (메타 루프)
- 상점(장비·소모품) / 대장장이(강화) / 의뢰판(퀘스트) / 저장고(보관 — **무료**)
- **세관 수수료 10% = 환전 시 공제.** 정의는 이 한 줄로 고정한다(보관료 아님, 반입가 기준 아님).
  브로카가 약탈품을 골드로 바꿔줄 때 매입가의 10%를 뗀다. 전 문서 이 정의를 따른다.
- 골드 손실 방어: 거점 장비만 구매 가능, 던전 내 구매 불가

### 강화 확률표 (도박 영업 — 08 밸런스의 기준 원본)
| 단계 | 성공 | 실패 시 |
|---|---|---|
| +1 | 90% | 변화 없음 |
| +2 | 75% | 강화도 −1 |
| +3 | 55% | 강화도 −1 |
| +4 | 35% | **파괴 45%** / 강화도 −1 55% |
| +5 | 20% | **파괴 70%** / 강화도 −1 30% |

## 승리 조건 / 패배 조건
- 세션 승리: 탈출 + 순가치(약탈−반입원가) > 0
- 세션 패배: 사망(전멸) 또는 조수 내 미탈출
- 메타 승리: 15~20시간 내 메인 퀘스트 완료 + 엔딩 도달 (분기 모드 연동)

## MVP 범위 (프로토타입)
1층 고정 맵 1개 + 게이트 2곳, PvE 몹 2종, **솔로 1인 + 듀오 코옵**, 인벤토리 8슬롯, 탈출/사망 판정, 거점 상점.
- PvP 매칭·봇 대체·안티치트 요구사항 전부 삭제 → **MVP 기술 난도가 대폭 하락**(권장 기간 4~6주, 기존 '2~3주'는 폐기)

## 확장 (V2)
- 트리오 코옵 밸런스 정식화, 캐릭터 클래스 4종(Q 고유 스킬), 시즌제 던전 변이, 레이드형 공유 보스, 빌드 시스템(유물 세트 효과)
