# 잔상 배선공: 6초 시간 하이스트 (Afterimage Wireman / Chrono Wirer)

> 기획 문서: `docs/INDIE_GAME_DISCUSSION_RETEST.md` 기반 구현  
> 장르: 1인 시간 복제 잠입/회로 액션 퍼즐 (6-Second Time Heist Action Puzzle)  
> 플레이 플랫폼: 웹 브라우저 (HTML5 Canvas + Web Audio API)

---

## 1. 핵심 기획 및 판타지

**"과거의 내가 다음 시도의 도구이자 때로는 장애물이 된다."**

플레이어는 6.0초(360 고정 물리 틱)의 루프 속에서 자신의 이동과 `E` 상호작용을 기록하고, 다음 루프에서 재생되는 과거 잔상(최대 2개 잔상 + 1 라이브 플레이어)과 실시간으로 협동하여 고보안 시설을 돌파합니다.

---

## 2. 핵심 게임플레이 특징

1. **6.0초 콤팩트 루프 & 즉각적인 아하 경험**:
   - 단 1회의 잔상 녹화만으로 문이 열리는 협동의 쾌감을 첫 20~30초 안에 체감.
2. **E 키 상호작용 및 잔상 물리 재현**:
   - 에너지 셀 및 금고 코어 줍기, 내려놓기, 반응로 소켓 삽입.
   - 잔상 또한 동일한 틱에 상호작용을 그대로 재현하여 **시간차 아이템 릴레이** 가능.
3. **Space 조기 확정 (Early Commit)**:
   - 자신의 몫을 마쳤다면 6초를 모두 기다리지 않고 `Space` 또는 `Enter`를 눌러 즉시 루프를 확정하고 다음 침투 개시.
4. **4대 하이스트 전술 룸 구현**:
   - **유인(Lure)**, **침투(Infiltrate)**, **전달(Relay)**, **동기화(Synchronize)**가 5개 작전 구역에 유기적으로 배치.

---

## 3. 5대 작전 구역 (Operation Zones)

1. **제1구역: 격벽 협업 (Blast Gate Cooperation)**
   - 상단 제어 스위치를 잔상 1이 누르고 있는 동안, 라이브 플레이어가 개방된 격벽을 질주 돌파.
2. **제2구역: 에너지 셀 시간 전달 (Energy Cell Relay)**
   - 잔상이 금고에서 에너지 셀을 집어(`E`) 중앙 인계 지점에 투하(`E`), 라이브 플레이어가 이를 가로채 반응로에 삽입(`E`).
3. **제3구역: 레이저 & 경비 유인 (Laser & Security Lure)**
   - 치명적인 보안 레이저를 통과하기 위해, 잔상이 기만 콘솔을 작동시켜 3초간 레이저를 무력화하는 사이 금고 코어를 탈취(`E`) 후 탈출.
4. **제4구역: 이중 회로 동기화 (Dual Circuit Synchronizer)**
   - 2개의 원격 단말기를 2개의 잔상이 동시에 누르고 있어야만 중앙 방폭문 개방.
5. **제5구역: 궁극의 하이스트 (Grand Vault Heist)**
   - 기만 콘솔 무력화, 에너지 셀 전달, 반응로 가동을 3개의 잔상과 완벽히 공조하여 탈출.

## 4. 조작 가이드

| 조작키 | 동작 | 설명 |
|---|---|---|
| `W` `A` `S` `D` / 방향키 | 이동 | 틱당 4픽셀 정수 이동 |
| `E` | **상호작용** | 아이템 줍기 / 놓기 / 반응로 삽입 |
| `Space` / `Enter` | **루프 조기 확정** | 6초 대기 없이 즉시 다음 잔상 침투 시작 |
| `R` | 즉각 재시도 | 현재 룸 초기화 |
| `1` ~ `5` | 구역 즉시 선택 | 5대 작전 구역 전환 |
| `P` / `Tab` | 일시정지 & 스크러빙 | `[` / `]` 키로 틱 단위 타임라인 확인 |
| `F3` | 기술 진단 패널 | 틱, 좌표, 커맨드 비트마스크 노출 |
