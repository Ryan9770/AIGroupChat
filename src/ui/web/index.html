선택하면 바로 적용됩니다. 일반 작업도 구현 담당에게 배정됩니다. 단계별 협업은 아래 ‘설계 → 구현 → 검토 만들기’를 사용하세요.

      

      

        고급 설정 · 역할별 예외와 자동 대체
        
역할별로 다른 담당을 지정할 수 있습니다. ‘프로젝트 기본값’은 서버 설정을 따르므로 실행 미리보기에서 확인하세요.

        

        
        
기본은 지정 모델만 사용합니다. 자동 대체를 켜면 로그인된 다른 모델도 후보에 포함됩니다. 작업별 직접 지정은 별도로 유지됩니다.
